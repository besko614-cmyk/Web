The important boundary

Public does not mean the catalog is public.

The release page has one job: request delivery for a fixed, named upload. It never accepts an arbitrary title or exposes storage details, so an anonymous visit cannot become a catalog browser.

  • Only Bloom after dark is eligible for anonymous delivery.
  • Watch and download controls wait for a temporary delivery URL.
  • Every other release still follows the existing sign-in or checkout path.
